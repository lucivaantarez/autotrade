# Evidence drop folder

Add new anonymized runtime evidence here using descriptive filenames, for example:

- `live_test_01_console.txt`
- `live_test_01_result.json`
- `live_test_01_screenshot.png`
- `live_test_01_notes.md`

Do not upload passwords, cookies, executor keys, webhook URLs, account lists, or private identifiers.

Read `INDEX.md` before adding evidence. For each new test, record:

- test name and date
- startup screen observed
- whether the account was already in-game
- manual actions performed
- before/after visible reward values
- whether the result persisted after reopening the UI
- what the evidence proves
- what remains unverified

The live adapter must remain disabled for mass rotation until the evidence supports the transition being tested.
